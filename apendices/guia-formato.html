LaTeX

En línea: \(f:\R^n\to\R\) es \(L\)-suave si \(\norm{\nabla f(x)-\nabla f(y)}\le L\norm{x-y}\). Las macros de _macros.qmd están disponibles en todos los capítulos.

En bloque, con etiqueta para referenciarla con @eq-gd:

\[ x_{k+1} = x_k - \eta\,\nabla f(x_k) \tag{1}\]

Teoremas y referencias

Teorema 1 (Descenso de gradiente, caso convexo) Si \(f\) es convexa y \(L\)-suave y \(\eta = 1/L\), entonces \(f(x_k)-f^\star \le \dfrac{L\norm{x_0-x^\star}^2}{2k}\).

Demostración. Por escribir.

El Teorema 1 usa la iteración Ecuación 1; ver también (Boyd y Vandenberghe 2004; Nesterov 2018).

Código y figuras

import numpy as np
import matplotlib.pyplot as plt

f = lambda x: x**2
eta, x = 0.3, 2.0
xs = [x]
for _ in range(8):
    x = x - eta * 2 * x
    xs.append(x)
xs = np.array(xs)

t = np.linspace(-2.2, 2.2, 200)
plt.plot(t, f(t))
plt.plot(xs, f(xs), "o-")
plt.show()

Animaciones

Con matplotlib (reproductor interactivo en HTML):

from matplotlib.animation import FuncAnimation
from IPython.display import HTML

fig, ax = plt.subplots()
ax.plot(t, f(t))
punto, = ax.plot([], [], "ro")

def update(k):
    punto.set_data([xs[k]], [f(xs[k])])
    return (punto,)

anim = FuncAnimation(fig, update, frames=len(xs), interval=500)
plt.close(fig)
HTML(anim.to_jshtml())

Interactiva, con Observable JS (el control actúa sobre la gráfica en el navegador):

})
